# Sqoch — оформление билетов

Адаптивное приложение для оформления заказа на событие. Интерфейс построен на React, TypeScript и Vite. Данные заказа хранятся в состоянии приложения и используются для демонстрации сценария без платёжного сервиса.

## Запуск

```bash
npm install
npm run dev
```

Vite покажет локальный адрес в терминале (обычно `http://localhost:5173`). Для production-сборки:

```bash
npm run build
npm run preview
```

## Проверка сценариев

1. Добавьте от одного до четырёх участников, укажите каждому имя и возраст, затем email заказа.
2. Цена билета автоматически составит 1 000 ₽ для возраста до 13 лет включительно и 2 000 ₽ для возраста от 14 лет.
3. Для участников младше 18 лет нужен хотя бы один взрослый от 18 лет в том же заказе.
4. Нажмите «Проверить заказ», проверьте состав и при необходимости вернитесь к редактированию.
5. Подтвердите заказ, чтобы увидеть успешный экран с номером заказа.
6. Для сценария нехватки мест включите переключатель «Места закончились» в блоке «Демо-сценарий» и подтвердите заказ. Заказ останется на экране проверки, а данные сохранятся.

## Структура

- `src/domain/booking.ts` — модель заказа, расчёт цены и валидация правил.
- `src/pages/BookingPage.tsx` — ввод участников и email.
- `src/pages/ConfirmationPage.tsx` — проверка заказа и обработка отказа.
- `src/pages/SuccessPage.tsx` — результат успешного оформления.
- `src/App.tsx` — состояние и переходы сценария.
- `src/styles.css` — визуальная система и адаптивная вёрстка.

Ориентировочные цены, площадка и дата — демонстрационные данные. Оплата и отправка email не подключены.
