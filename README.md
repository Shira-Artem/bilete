# Sqoch — оформление билетов

Адаптивное демонстрационное приложение для проверки сценария заказа билетов. Интерфейс построен на React, TypeScript и Vite. Данные хранятся только в состоянии страницы и не отправляются на сервер.

## Запуск

```bash
npm install
npm run dev
```

Vite покажет локальный адрес в терминале (обычно `http://localhost:5173`). Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

## Тесты

```bash
npm test
```

Для интерактивного режима:

```bash
npm run test:watch
```

## Демо-сценарии

**Успешное оформление:** укажите имя, возраст и email, нажмите «Проверить заказ», проверьте заказ и выберите «Создать демо-заказ». Приложение покажет демонстрационный номер заказа.

**Нет свободных мест:** до подтверждения включите переключатель «Места закончились» в блоке «Демо-сценарий», затем пройдите проверку и нажмите подтверждение. Приложение покажет отказ, сохранит введённые данные и позволит вернуться к редактированию. После отключения сценария можно проверить успешное оформление.

## Правила заказа

- От 1 до 4 участников.
- Полный билет от 14 лет стоит 2 000 ₽; детский билет для возраста младше 14 лет — 1 000 ₽.
- Любой участник младше 18 лет должен быть в одном заказе хотя бы с одним участником от 18 лет.
- На заказ указывается один email.
- До подтверждения данные можно изменить.

## Структура

- `src/domain/booking.ts` — модель заказа, расчёт цены, проверка возраста и валидация правил.
- `src/pages/BookingPage.tsx` — ввод участников и email.
- `src/pages/ConfirmationPage.tsx` — проверка состава заказа и сценарий отсутствия мест.
- `src/pages/SuccessPage.tsx` — результат успешного демо-оформления.
- `src/App.tsx` — состояние и переходы сценария.
- `src/styles.css` — визуальная система и адаптивная вёрстка.

## Ограничения

Это моковая реализация: backend и постоянное хранение отсутствуют; остатки мест задаются переключателем; оплата не проводится; письма и билеты не отправляются. Номер заказа демонстрационный и действует только в текущей сессии страницы. Дата, площадка и событие приведены для примера.
